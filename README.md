# Space School
A build-free interactive website made with HTML, CSS, and JavaScript. No libraries, external fonts, or network assets are required.

## Preview
Open index.html in a browser, or run `python3 -m http.server 8000` from this folder.

## GitHub Pages
Upload index.html, style.css, and app.js to the root of your GitHub repository. In Settings → Pages, select Deploy from a branch, choose your branch and /(root), and save.

All paths are relative, so repository-based GitHub Pages URLs work. Mission progress is saved locally in the visitor's browser when storage is available. Activities are simplified educational models, not real mission simulations.

The Curiosity System includes six selectable planets, three short mission stages, a completion celebration, and a printable certificate unlocked after all six missions. Saved progress from earlier versions is preserved.
